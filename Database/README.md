# Banco de dados local

O backend usa SQLite e cria `saudeconecta.sqlite` nesta pasta quando inicia. As tabelas são definidas em `schema.sql`; cada conjunto de registros é separado pelo ID do perfil de paciente.

Para consultar durante a demonstração, use qualquer cliente SQLite e abra `saudeconecta.sqlite`. O botão **Simular dados** popula as tabelas do perfil escolhido.
